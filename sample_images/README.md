# Sample Images

Use these three images for the final demo:

1. Man sitting on a chair using a laptop
2. Lion standing in a forest
3. Children playing soccer on a field

Place them in this folder with these filenames before recording the demo:

```text
sample_1_laptop.png
sample_2_lion.png
sample_3_soccer.png
```

The app also supports uploading any other JPG or PNG image.
